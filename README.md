# Orchestrate Next

Working name for a fresh project to improve autonomous software engineering for nontechnical users of coding agents.

## Outcome

One easy-to-install solution that helps an agent understand a user's vision, make sound engineering decisions, retain relevant context, adapt when assumptions fail, and deliver verified working software with less wasted usage and human steering.

Claude Code is the first intended host. Codex and supported ChatGPT environments are desired additional hosts; compatibility and benefit must be established for each surface. Subscription changes should require no manual plugin tier configuration.

## Current state

Planning only. There is no plugin, runtime, installer, selected implementation language, or demonstrated performance improvement. The architecture is open. This repository does not import either predecessor's implementation or roadmap.
